# SpecPilot User Guide

SpecPilot turns a product description into first-draft documentation.

## 1. Describe the product

- **Product Title** — a short name for the product.
- **Product Details** — describe the product as fully as you can.

## 2. Choose document types

Select one or more:

- **Product Requirements Document (PRD)** — problem, business case, solution, requirements,
  personas, exclusions, success criteria, assumptions, and risks.
- **Technical Requirements Specification (TRS)** — summary, architecture, boundaries,
  non-functional requirements, data, integration, UI, testing, deployment, and AI usage.
- **UX Design Mockups** — user journeys for personas and UI design mockups.

## 3. Generate

Click **Generate**. Only the selected documents are produced. If the title or details are
empty, or no type is selected, a message explains what is missing.

## 4. Review and edit

Switch between the **PRD**, **TRS**, and **UX** segments. Edit the generated text directly;
edits are kept while you switch segments during the session.

## 5. Export

- **Export Word** or **Export PDF** downloads the current document. The file name is prefixed
  with the product title (for example `acme-prd.docx`).
- **Download UX** saves the UX mockups to your computer.

## 6. Iterate

Change the inputs or the selected types and generate again. Regenerated output replaces the
previous output for those types.

## Privacy

Your content is processed in memory to build the response and downloads. The server keeps no
copy of your content.
